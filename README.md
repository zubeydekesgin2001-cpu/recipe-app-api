# Recipe App API

A recipe management API developed with FastAPI and SQLite.

## Features

* Create recipes
* Update recipes
* Delete recipes
* List recipes
* API routing structure
* Database integration
* Frontend support

## Technologies Used

* Python
* FastAPI
* SQLite
* SQLAlchemy

## Project Structure

* routers/
* services/
* database.py
* models.py
* schemas.py
* frontend/
